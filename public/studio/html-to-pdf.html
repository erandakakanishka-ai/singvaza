HTML / Code → PDF

Paste HTML, Markdown or source code and get a clean PDF. Choose A4, A5 or Letter, portrait or landscape, margins, page numbers and syntax colours — a printable document or a plain edge-to-edge PDF. Everything runs on your device: nothing is uploaded and there is no file limit.

Page setup

Printable adds readable margins, a document header, a footer and page numbers — ready for a printer.

Export

“Download PDF” builds the file here in the browser. “Print / Save as PDF” uses the browser's own PDF engine — handy on phones, where it also previews the pages exactly.

Good to know

• A4 / A5 / Letter / Legal / A3, portrait or landscape.
• Printable = margins + header + footer + page numbers; Plain PDF = edge to edge.
• Page breaks land between blocks, never through a line; long code blocks split at their own line breaks.
• Code keeps its long lines instead of being cut.
• Works offline once loaded. No uploads, no accounts.

Everything on this page runs in your browser. Your document is never sent to a server — there is no upload step, which is why the tool works offline and has no size limit.
