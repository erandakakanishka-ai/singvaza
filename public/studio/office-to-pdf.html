Export

On a phone, “Print / Save as PDF” is often the easiest way to keep the file — it opens the system print sheet, where “Save as PDF” is one tap away.

Good to know

• Text, headings, lists, tables and slide text are converted. Photos inside a Word file are not drawn yet — the text layout is.
• Old .doc / .xls / .ppt files must be saved in the newer format first.
• Excel: the first 400 rows of each sheet.
• Nothing is uploaded, so there is no size limit and no queue.
